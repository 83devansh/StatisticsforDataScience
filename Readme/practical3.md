# Teaching Ratings Data Analysis Using Pandas

## Introduction
This project focuses on analyzing the Teaching Ratings dataset using Python. It includes data cleaning, duplicate identification, statistical calculations, data visualization, and correlation analysis.

## Libraries Used
- Pandas
- Matplotlib
- Seaborn

## Tasks Performed

1. Loaded the Teaching Ratings dataset using Pandas.
2. Identified duplicate observations using the professor ID (`prof`).
3. Calculated the mean and standard deviation of age using all observations.
4. Removed duplicate observations and kept only one record for each professor.
5. Calculated the mean and standard deviation of age after removing duplicates.
6. Created a bar chart to compare teaching evaluations for lower-division and upper-division courses.
7. Created a scatter plot to study the relationship between age and teaching evaluation.
8. Calculated the correlation between age and teaching evaluation.
9. Created a scatter plot showing age and teaching evaluation by gender.
10. Created a scatter plot showing age and teaching evaluation by gender and tenure.

## Dataset Information
- Dataset: Teaching Ratings
- Total Observations: 463
- Total Columns: 19
- Unique Professors: 94

## Results
- Identified duplicate observations using professor ID.
- The average age using all observations is approximately 48.37 years.
- After removing duplicates, the average age is approximately 47.55 years.
- Lower-division courses have higher average teaching evaluations than upper-division courses.
- The correlation between age and teaching evaluation is -0.0517, indicating a very weak negative relationship.
- Scatter plots show no strong relationship between age and teaching evaluation based on gender and tenure.
