# Teachers' Ratings Data Analysis Using Pandas

## Introduction
This project focuses on analyzing the Teachers' Ratings dataset using Python. It includes data exploration, duplicate identification, statistical calculations, and data visualization.

## Libraries Used
- Pandas
- Matplotlib

## Tasks Performed

1. Loaded the Teachers' Ratings dataset using Pandas.
2. Displayed the first five rows, dataset shape, and column names.
3. Identified duplicate records using `prof_id`.
4. Calculated the average and standard deviation of professors' age.
5. Removed duplicate records and kept one observation for each professor.
6. Calculated the average and standard deviation of age after removing duplicates.
7. Created a bar chart to compare average teaching evaluations for lower and upper division courses.
8. Created a scatter plot to show the relationship between age and teaching evaluation scores.
9. Created gender-differentiated scatter plots to compare age and teaching evaluation scores.
10. Created a scatter plot to compare age and teaching evaluation scores based on gender and professor rank.

## Dataset Information
- Dataset: Teachers' Ratings
- Total Observations: 463
- Total Columns: 23
- Unique Professors: 94

## Results
- Identified 456 rows belonging to professors with multiple observations.
- Average age using all observations is approximately 48.37 years.
- Average age after removing duplicates is approximately 47.23 years.
- The dataset contains 306 upper-division and 157 lower-division course observations.
- Scatter plots were used to examine teaching evaluation scores based on age, gender, and rank.
