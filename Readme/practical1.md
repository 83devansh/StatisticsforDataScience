# Customer Data Analysis Using Pandas and NumPy

## Introduction
This project demonstrates basic data analysis and preprocessing using Python. It uses a customer dataset containing age, gender, review, education, and purchase information.

## Libraries Used
- Pandas
- NumPy
- Scikit-learn

## Tasks Performed

1. Loaded the customer dataset using Pandas.
2. Displayed and explored the dataset.
3. Used `describe()` to get statistical information.
4. Checked the shape, size, and dimensions of the dataset.
5. Converted categorical data into numerical values using Label Encoding.
6. Used mapping to convert review values:
   - Poor = 0
   - Average = 1
   - Good = 2
7. Created NumPy arrays.
8. Performed addition, subtraction, multiplication, division, and power operations.
9. Calculated maximum, minimum, sum, and mean.
10. Performed matrix transposition using NumPy.

## Dataset Information
The dataset contains 50 rows and 5 original columns:
- Age
- Gender
- Review
- Education
- Purchased
