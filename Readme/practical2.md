# Teachers' Ratings Data Analysis

## Introduction
This project focuses on analyzing the Teachers' Ratings dataset using Python. It includes data exploration, descriptive statistics, data visualization, and statistical hypothesis testing.

## Libraries Used
- Pandas
- NumPy
- Matplotlib
- SciPy

## Tasks Performed

1. Loaded the Teachers' Ratings dataset using Pandas.
2. Identified whether the dataset is cross-sectional or time-series data.
3. Calculated the mean, median, minimum, and maximum number of students.
4. Generated descriptive statistics using `describe()`.
5. Created a histogram to analyze the distribution of professors' beauty scores.
6. Calculated the mean and standard deviation of beauty scores for male and female professors.
7. Performed an independent t-test to check whether beauty scores differ by gender.
8. Calculated the percentage of male and female tenured professors.
9. Performed a Chi-Square test to check the association between gender and tenure status.

## Dataset Information
- Dataset: Teachers' Ratings
- Total Records: 463
- Total Columns: 23
- Unique Professors: 94

## Statistical Tests Used
- Independent T-Test
- Chi-Square Test

## Results
- The dataset is cross-sectional.
- Average number of students per course is approximately 55.18.
- Female instructors have a higher average beauty score than male instructors, but the difference is not statistically significant.
- Male professors have a higher percentage of tenure than female professors.
- There is no statistically significant association between gender and tenure status at the 5% significance level.
